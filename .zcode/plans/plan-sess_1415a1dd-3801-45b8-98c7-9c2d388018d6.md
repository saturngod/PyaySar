## Goal
Allow downloading an invoice PDF from the `/invoices` list page (per-row Actions dropdown), not only from the detail page.

## Root constraint
Index rows are lightweight (id, number, total, status, customer.name) but `generateInvoicePdf` needs the full invoice (items, customer.avatar_url, notes, currency, etc.) + userPreference. So downloading from the list fetches the full data on demand.

## Changes

1. **`app/Http/Controllers/InvoiceController.php`** — add `showJson(Invoice $invoice)`:
   - Manual ownership guard: `if ($invoice->user_id !== Auth::id()) abort(403);`
   - `$invoice->load(['items', 'customer'])` + `Auth::user()->preference`
   - `return response()->json(['invoice' => $invoice, 'userPreference' => Auth::user()->preference]);`
   (Loading customer/preference makes the `avatar_url` / `company_logo_url` accessors fire, so the PDF image pre-fetch gets signed URLs.)

2. **`routes/web.php`** — inside the existing `['auth','verified']` group:
   `Route::get('/invoices/{invoice}/json', [InvoiceController::class, 'showJson'])->name('invoices.json');`

3. **`resources/js/pages/invoices/index.tsx`** — add a "Download PDF" `DropdownMenuItem` (lucide `Download` icon) to the per-row Actions menu. Handler:
   - `const { data } = await axios.get(\`/invoices/${invoice.id}/json\`)`
   - `await generateInvoicePdf(data.invoice, data.userPreference)`
   - Add `downloadingId` state to show "Downloading…" / disable the item while in flight. Import `axios`, `Download`, `generateInvoicePdf`.

4. **New `tests/Feature/InvoiceTest.php`** (Pest) per `ItemTest.php` conventions:
   - test: `invoices.json` returns 200 with full shape (has `invoice.items`, `invoice.customer`, `userPreference`)
   - test: returns 403 for another user's invoice (ownership)

## Out of scope
No changes to the PDF generator, detail-page button, or backend PDF logic. No change to the lightweight index row type.

## Verification
`./vendor/bin/pint` → `npm run types` → `composer run test` (or `./vendor/bin/pest tests/Feature/InvoiceTest.php`).
